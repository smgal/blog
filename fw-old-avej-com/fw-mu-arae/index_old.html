사람은 누구나 자신이 주인공이 되는 별을 하나씩 가지고 태어난다.
비록 지금 당신이 있는 이 별이 당신을 주인공으로 맞아들이지 않더라도
밤 하늘의 수 많은 별들 중에 하나의 별은 분명 당신이 주인공인 별이다.

지금 이야기 하고자 하는 것은 당신이 주인공이 되는 그 별에 대한 것이다.
오직 당신 하나만을 위해서 존재하고 당신의 소멸과 함께 사라지는 그 별 말이다.

내가 시간을 도약하는 날개를 달고 아득한 저편의 우주를 향해 날개짓을
시작했을 때 당신의 별은 태어났다.

나에게나 당신이 아닌 다른 누구에게는 그저 흔한 그런 별 중에 하나이겠지만
당신에게는 단 하나뿐인 당신의 별이 될 그것이 태어났다.

지금부터 당신은 내가 준 날개를 펼쳐 당신의 별로 날아 올라야 한다.
당신이 현실이라고 믿고 있던 지금의 별은, 당신에게는 그저 흔한 그런 별로
생각해야할 때가 온 것이다.

당신이 주인공인 그곳. 숙명과 같은 짐을 진 채 그들 앞에 당당하게 서는 그곳.
그곳으로 당신을 초대한다 !

목적

지하철 타고 다닐 때 할 만한 게임이 없어서 내가 하나 만들겠다.
 

특징

1.

내가 즐기기 위한 목적으로 만든다.

2.

이것은 90년에 만들었던 나의 7번째 게임을 리메이크할 것이다.

3.

PC에서 동작하기는 하지만 기타 게임기나 PDA에서 구동되기 때문에 지하철에서도 게임을 할 수 있다.

4.

밖에서 다른 기기를 통해서 했던 게임의 세이브가 PC와 연동된다.

5.

일단 하나의 코드로 Windows PC, Embedded linux, 하나 이상의 PDA, 하나 이상의 게임기에서 구동 가능하다.

6.

게임에 있어서 부수적인 효과들을 최대한 제거해서, 빠르고 간단한 게임이 되도록 한다.

7.

언제나 마음만 먹으면 3D 온라인 게임도 될 수 있도록 확장성을 고려하여 설계한다. (단, 처음부터 설계될 필요는 없고 추가 설계가 용이하도록 확장 방식을 사용한다.)

8.

코어에서 OS에 대한 디펜던시는 없다. 모든 OS와 하드웨어를 추상화시킨다.

9.

일부, CPP을 지원하지 않는 게임기와 OS를 위해 래퍼를 구성한다.

10.

그래픽 효과를 위해 비용을 투자하지 않는다.

AVEJ windows 버전 최상위 코드

#include <windows.h>
#include "avej.h"

IAvejVideo* pAvejVideo = NULL;
CAvejMain*  pAvejMain  = NULL;

int AppMain(HINSTANCE hInstance)
{
        CAvejAppWin32  avejApp;
        OZAPPINIT_DESC appInitDesc;

        ZeroMemory(&appInitDesc, sizeof(appInitDesc));
        appInitDesc.hInstance    = UINT32(hInstance);
        appInitDesc.width        = SCREEN_WIDTH;
        appInitDesc.height       = SCREEN_HEIGHT;
        appInitDesc.depth        = SCREEN_DEPTH;
        appInitDesc.isFullScreen = false;

        avejApp.Init(appInitDesc);
        avejApp.Run();
        avejApp.Done();

        return 0;
}

int WINAPI WinMain(HINSTANCE hInstance, HINSTANCE hPrevInstance,
                   LPTSTR lpCmdLine, int nCmdShow)
{
        return AppMain(hInstance);
}


AVEJ의 스크립트 엔진을 만들기 귀찮아서 그냥 아래의 것으로 대체했다.
마치 스크립트처럼 보이지만 교묘한 #define을 통해 일반 C함수로 컴파일이 된다.

완성후 스크립트만 재배포하는 방식은 이제 어려워졌을지는 모르겠지만
적어도 컴파일러가 스크립트의 문법 체크까지 해주고 커맨드 확장하는 것도 쉬워졌다.
그리고 복잡한 스크립트는 그냥 C문법으로 삽입할 수도 있으니 나름대로의 장점도 가지는 것 같다.

#include "avejScript.h"

def(001)

   keyword("SYSCMD_description")
      Talk("이 사람은 이곳 주점의 주인겸 바텐더다.")
      Talk("그다지 신뢰가 가지 않는 얼굴에 능글 맞은 말투까지 갖추었으니, \
           과히 속물이라고 할수도 있겠다. 하지만 젊었을 때는 비합법적인 \
           조직의 일을 꽤나 했었다고 자랑스럽게 말하곤 한다. 다 믿을 수는 \
           없는 말들이지만 그래도 그가 수집하는 정보의 양이나 질로 보면 \
           그 말들이 모두 틀린 것은 아닌 것 같다.")

   keyword("SYSCMD_look")
      Talk("실실 웃으면서 컵을 닦고 있는 모습에서 보면, \
           외모로는 그다지 호감을 주지 못하는 타입이다.")

   keyword("SYSCMD_default")
      if GetScriptFlag(ixMetBartender) then
         Talk("천천히 쉬다가게. 기사거리나 좀 알려줄까?")
      otherwise
         Talk("여어... 기자 양반 아니신가. 어인 일로 이런누추한 곳까지 \
              다 찾아 오셨나? 뭐 기사거리라도 찾고 계신겐가?")
      endif

      SetScriptFlag(ixMetBartender);

      RemoveKeyWord("SYSCMD_description")
      RemoveKeyWord("SYSCMD_look")
      RemoveKeyWord("SYSCMD_default")
      RegisterKeyWord("기사거리")

   keyword("기사거리")
      Talk("뭐, 지난 번에 알아봐 달라고 한 그거 말일세. 나름대로는 \
           힘들게 찾아 보았다네. 그래서 그럭저럭 쓸만한 정보는 몇 개 \
           얻었는데 말야. 어때? 관심있나?")

      RemoveKeyWord("기사거리")
      RegisterKeyWord("예")
      RegisterKeyWord("아니오")

   otherwise
      Talk("내가 모든 것을 알고 있다고 생각하면 오산이야.")

enddef
